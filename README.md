# Forever Class & Race Calculator

Fan-made class and race planner for World of Warcraft: Forever. Not affiliated with Blizzard Entertainment.

Pick a faction, role, what you want to do (Pure PvP, PvE, Balanced, Casual or Gold farmer), your experience and a profession priority, and every race and class path re-ranks as you click. Open a path to see why it scored the way it did, compare up to three, and read the race and class guides. Choices are saved in the link, so you can share a set of picks.

Press **Plan talents & gear** on any result to open the planner: the expected best talents for that spec and a starter gear set, which you can then change talent by talent and slot by slot. The build saves in the link too. Talents marked **F** carry a reported Forever change, listed beside the tree with its source.

Ratings are provisional until beta tooltips and combat logs confirm them; the "How it scores" tab says what is current and what is not. The planner's talent trees and item list are Classic-era data until Forever beta data exists.

The page is two files with no build step: `index.html` and `planner-data.js` (loaded only when the planner opens). Keep them together, or use the published site.
